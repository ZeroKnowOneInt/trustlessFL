# FMNIST 공격·동적 참여: 공식 Flower Runtime 소규모 검사

공식 `flwr run`/SuperLink/Ray simulation에서 N=8, 라운드 참여 q=4,
aggregator 4개, 공격 client 2명, 2라운드를 실행했다. 첫 라운드에는
client-0/1이 공격하고, 둘째 라운드에는 두 client가 참여하지 않는다.
Fashion-MNIST/LeNet5와 고정 `avg_300.pth` checkpoint를 사용했다.
각 모드는 새 identity·FAB·Flower run을 갖는다.

| 경로 | 1라운드 정확도 / ASR | 2라운드 정확도 / ASR |
|---|---:|---:|
| AION-ASR | 10.00% / 100% | 61.68% / 17.1875% |
| 평문 양자화 | 10.00% / 100% | 61.68% / 17.1875% |
| 평문 평균 | 10.00% / 100% | 61.65% / 17.578125% |
| 평문 artifact-style MGF | 86.28% / 1.171875% | 87.55% / 0.390625% |

AION과 동일 참여자의 평문 양자화 모델은 모든 라운드에서 정확히 일치했다
(최대 절대 오차 0). MGF는 첫 라운드에 4명 중 client-4/5를 선택해
공격 client-0/1을 제외했다. 이는 평문 update를 중앙에서 읽는 **ML 대조군**이지
AION의 보안 집계/MGF 결합 결과가 아니다. q=4에서는 논문의 q=100 선택 하한
10%가 0명이 되므로, 구현은 2명 하한으로 조정한다. 따라서 MGF 수치를
논문 규모의 방어 성능으로 해석하지 않는다.

`13210587159636639428`, 평균 `6840123196131580016`, MGF
`3800569622016771018`이다. 원시 실행과 `verification.json`은
`/tmp/trustlessfl-fmnist-official-dynamic-20260929`에 있고, 검증 파일의
SHA-256은 `c947201a71e9de287d8f3acab163c05b4517e3e2c664288ad3d138a20330af48`이다.

60라운드와 보안성 검증은 이 결과에 포함되지 않는다.
